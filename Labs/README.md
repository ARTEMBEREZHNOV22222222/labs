# Рішення лабораторних робіт — варіант 3

Реалізації індивідуальних завдань знаходяться у `Labs/Lab1/solution.py` … `Labs/Lab11/solution.py`. Для запуску потрібен Python 3.10+ без зовнішніх пакетів.

Приклад запуску: `python Labs/Lab3/solution.py`.

ЛБ8: `python Labs/Lab8/solution.py --path <каталог> --mask 777`.

ЛБ10: `python Labs/Lab10/solution.py` (використовує тестові `traffic.csv` та `traffic_sample.bin`, генерує CSV і JSON звіти).

РГР: методичні вказівки містять список типових тем, але не встановлюють відповідність теми номеру варіанта. Тему РГР не призначено без підтвердження користувача.
