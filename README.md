# Python Basic Level Course

Навчальний репозиторій для лабораторних робіт, контрольного завдання та розрахунково-графічної роботи з курсу Python: базовий рівень.

## Структура

- `Labs/` — лабораторні роботи `Lab1`–`Lab11`.
- `Контрольне завдання/cluster_telemetry/` — контрольне завдання з аналізу кластерної телеметрії.
- `РГР/data/` — вхідні дані.
- `РГР/license_audit/` — модулі аудиту та оптимізації ліцензій.
- `РГР/output/` — результати виконання та звіти.

## Примітка

Структуру каталогів створено за наданим публічним прикладом. Вміст чужих лабораторних робіт, програмного коду та документів не копіювався. Додавайте сюди власні файли та результати робіт.
