# Навчальні матеріали

Репозиторій для лабораторних робіт, контрольних завдань і проєктних матеріалів з курсу Python Basic Level.

## Структура

- `Labs/` — лабораторні роботи `Lab1`–`Lab11`.
- `Контрольные задания/cluster_telemetry/` — контрольне завдання з аналізу телеметрії.
- `PRP/` — матеріали проєкту, дані, аудит ліцензій та результати.

> Примітка: зараз у репозиторії створено каркас каталогів за наданим скриншотом. Оригінальні файли лабораторних, презентація та пояснювальна записка потребують вихідного архіву — їхній вміст неможливо відновити зі скриншота.
